# SonicStars Web

Audio-driven warp-field and spectrum-highway visualizer.

## Run locally

```sh
./serve.sh        # http://localhost:8765, opens your browser; Ctrl+C to stop
```

Open or drop an audio file (plus an optional `.lrc` for synced lyrics).

Keys: `Space` play/pause, `←/→` seek 5s, `↑/↓` volume, `L` loop, `S` stop,
`F` fullscreen.
